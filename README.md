# 厳密ネットキャッシュ比率スクリーナー

清原達郎氏『わが投資術』のネットキャッシュ株の考え方に基づく日本株スクリーニングアプリです。

## セットアップ

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 使い方

1. サイドバーの「対象銘柄コード」欄に、スクリーニング対象としたい東証銘柄コードを
   カンマ区切りで入力します（例: `7203.T, 6758.T, 8306.T`）。証券会社のスクリーナー等で
   エクスポートしたコードリストをそのまま貼り付けても構いません。
2. 「計算パラメータ」で負債倍率（デフォルト1.1）・投資有価証券の割引率（デフォルト0.7）を
   必要に応じて調整します。
3. 「フィルター条件」でネットキャッシュ比率・時価総額・PBR・PER・自己資本比率の
   しきい値を設定します。
4. 「🔍 スクリーニング実行」を押すとyfinance経由でデータを取得し、計算結果を
   一覧表示します。ネットキャッシュ比率が高い順に自動ソートされます。
5. 結果は「⬇️ CSVダウンロード」ボタンからCSVとして保存できます。

## 計算ロジック

```
Net Cash = 流動資産 - (負債合計 × 負債倍率) + (投資有価証券 × 有価証券倍率)
1株ネットキャッシュ = Net Cash ÷ 発行済株式数
ネットキャッシュ比率 = 1株ネットキャッシュ ÷ 現在株価
乖離率(%) = (1株ネットキャッシュ - 現在株価) ÷ 現在株価 × 100
```

## デプロイ

GitHub（パブリックリポジトリ）＋ Streamlit Community Cloud の組み合わせで、
維持費0円のまま公開できます。

1. 本リポジトリの内容（`app.py`, `requirements.txt`, `README.md`, `.gitignore`）を
   GitHubのパブリックリポジトリにpush
2. [share.streamlit.io](https://share.streamlit.io) にGitHubアカウントでサインイン
3. "New app" からリポジトリ・ブランチ・メインファイル（`app.py`）を指定してデプロイ
4. 数分後に `https://xxxxx.streamlit.app` の公開URLが発行される

以後はGitHubにpushするだけで自動反映されます（サーバー管理・再デプロイ操作は不要）。
無料枠のアプリは長期間アクセスがないとスリープしますが、次回アクセス時に自動で
再起動します。

## 今後の拡張予定（段階的実装）

現在はyfinanceのみでデータを取得していますが、balance_sheetの項目名の
表記ゆれや欠損（特に「投資有価証券」）が発生しやすいという制約があります。

今後、以下の順で拡張する計画です。

1. **現行版（yfinanceのみ）をデプロイし、動作確認を行う** ← 現在ここ
2. **EDINET API連携を追加**し、金融庁が提供する有価証券報告書のXBRLデータから
   流動資産・負債合計・投資有価証券をより正確に取得する
   - EDINET APIはAPIキー登録が必要な仕様のため、キーは`.streamlit/secrets.toml`
     （Community Cloud側はSecrets管理画面）で管理し、リポジトリにはコミットしない
   - yfinanceのデータをデフォルトとしつつ、EDINETが取得できた銘柄は
     EDINET側の数値で上書き（またはユーザーが切替可能）にする設計を想定

## 注意事項

- データソースは無料の `yfinance`（Yahoo! Finance非公式ラッパー）のため、
  項目名の表記ゆれや決算期のズレにより一部データが欠損する場合があります。
  欠損した項目は0円として扱い、画面上の「欠損項目」列で明示されます。
- yfinanceにはTSE全銘柄を横断検索するAPIが存在しないため、対象銘柄コードは
  手動で指定する方式になっています。証券会社のスクリーニング機能等で
  中小型株のコードリストを事前に用意することをおすすめします。
- 本アプリは教育・情報提供目的であり、投資助言ではありません。
